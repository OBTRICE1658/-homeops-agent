# Deploy CRM Demo for Notion Embedding

## Quick Deploy Options:

### 1. Netlify Drop (Easiest)
1. Go to https://app.netlify.com/drop
2. Drag and drop your `crm-agent-mockup.html` file
3. Get instant public URL
4. Embed in Notion using `/embed` command

### 2. GitHub Pages
1. Create new repo: `crm-demo`
2. Upload `crm-agent-mockup.html` as `index.html`
3. Enable GitHub Pages
4. Get URL: `https://yourusername.github.io/crm-demo`

### 3. Vercel (Professional)
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in folder with HTML file
3. Get instant deployment URL

## Notion Embedding:
- Use `/embed` command in Notion
- Paste your public URL
- Resize the embed block as needed
- The interactive demo will work directly in Notion!
